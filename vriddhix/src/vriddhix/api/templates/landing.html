One direction, no shortcuts

Each stage reads only what the stage before it produced, which is what makes any number traceable back to a bar.

  1. 01DataNSE daily bars, validated. Nothing silently dropped or repaired.
  2. 02FeaturesEMA, ATR, returns, 52-week extremes, relative volume — strictly causal.
  3. 03DetectionVCP contractions, BOS and CHoCH, order blocks, fair value gaps.
  4. 04ContextMarket regime, breadth, relative strength, sector rotation.
  5. 05ScoringWeighted components — every one stored, every one shown.
  6. 06TrackingThe breakout ledger: confirmed, failed, and why.
  7. 07BacktestThe same detector replayed, with costs and survivorship stated.

Four commitments

Constraints, not features. Each one costs something — which is how you can tell they are real.

one implementation

The backtest cannot drift from the scanner

Live scanner, backtester and X-Ray call the same function objects. There is no second implementation to drift from, and a test walks the syntax tree to keep it that way.

causality

Nothing may see the future

Verified by truncating history, recomputing, and demanding identical output. A look-ahead bug never crashes — it produces a backtest that looks excellent and means nothing.

honest nulls

It says what it does not know

An unranked sector reads null, not 0. Absence is never quietly rendered as a bearish number.

failures kept

Nothing that failed is deleted

Failed breakouts stay in the ledger with their reason, and no view drops them by default.

Read the data yourself

Watchlists, saved screens built on the same evaluator the backtester uses, and alerts over stored scan results. Free.
