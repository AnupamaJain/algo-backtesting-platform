Four commitments

These are not features. They are the constraints the system is built around, and each one costs something — which is how you can tell they are real.

one implementation

The backtest cannot drift from the scanner

The live scanner, the backtester, the historical X-Ray and the research queries call the same function objects — not the same algorithm written twice. There is no second implementation to drift from. A test walks the syntax tree to enforce it, because a convention is something people forget at 2am.

causality

Nothing may see the future

A value dated t depends only on bars dated t or earlier. Verified by truncating history at a date, recomputing, and demanding identical output — on synthetic data, on real NSE history, and across an unadjusted bonus issue. A look-ahead bug never crashes; it produces a backtest that looks excellent and means nothing.

honest nulls

The database says what it does not know

An unranked sector's strength is null, not 0 — "no standing" and "ranked last" are different claims. A win rate over zero resolved trades is null, not 0%, which would read as "this has never worked". Absence is never quietly rendered as a bearish number.

failures kept

Every breakout that failed is still here

Failed breakouts stay in the ledger with the reason and the day it happened, and no view filters them out by default. A hit rate computed over survivors is the single most flattering lie a research tool can tell, and it is the easiest one to tell by accident.

What it is, and what it isn't

Not this

  • No price targets, forecasts, or "expected return" figures.
  • No buy and sell calls. A grade classifies a chart's measured behaviour; it is not a recommendation.
  • No tips, no signals service, no portfolio management.
  • No claim that a pattern will repeat. The ledger records what followed each one — that is a measurement, not a promise.

This

  • Detection you can audit: every score decomposes into named, weighted components read from stored rows.
  • Context on every setup: market regime, sector standing, relative strength, all computed the same day.
  • A research database that accumulates — the same detector replayed across history, with outcomes attached.
  • Backtests that state their own survivorship mode in the results, so a biased universe travels with the numbers.

The pipeline

One direction, no shortcuts. Each stage reads only what the stage before it produced, which is what makes a number traceable back to a bar.
