One direction, no shortcuts

Each stage reads only what the stage before it produced, which is what makes any number traceable back to a bar.

  1. 01DataNSE daily bars, validated. Nothing silently dropped or repaired.
  2. 02FeaturesEMA, ATR, returns, 52-week extremes, relative volume — strictly causal.
  3. 03DetectionVCP contractions, BOS and CHoCH, order blocks, fair value gaps.
  4. 04ContextMarket regime, breadth, relative strength, sector rotation.
  5. 05ScoringWeighted components — every one stored, every one shown.
  6. 06TrackingThe breakout ledger: confirmed, failed, and why.
  7. 07BacktestThe same detector replayed, with costs and survivorship stated.

What it refuses to do

Four constraints. Each one costs something — which is the only reason to believe they are real.

There is one implementation of every rule
The live scanner, the backtester and the historical X-Ray call the same function objects. Not the same algorithm written twice — the same objects.
Costs: engines cannot take shortcuts that only make sense live, and a test walks the syntax tree on every commit to keep it that way.
Nothing may see the future
A value dated t depends only on bars dated t or earlier, checked by truncating history, recomputing, and requiring byte-identical output.
Costs: a swing is not confirmed until the bars that confirm it have printed, so the detector is always some days behind the chart a human would draw.
It says what it does not know
An unranked sector reads null, not 0. A win rate over zero resolved trades is null, not 0%.
Costs: every chart and every caller has to handle absence, because absence is never quietly rendered as a bearish number.
Nothing that failed is deleted
Failed breakouts keep their row, their reason and the day it happened. No view drops them by default.
Costs: the hit rate on this page is lower than the one a platform reports when it quietly counts only survivors.
